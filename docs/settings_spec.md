# Settings spec (summary)

Grouped settings shell:

- **App**: module management (max nav items via overflow).
- **Family & calendar**: Family Hub settings (add/edit/delete, export-before-delete), event categories linked to people, notifications/calendar defaults (stubs).
- **Support & sensitivity**: support presets; status shield and sharing/privacy in later phases.

Full tree (Sections 1–16) is phased: 1B shell → 1D content → 2A sync/sharing.

See `lib/screens/settings/settings_screen.dart`.
